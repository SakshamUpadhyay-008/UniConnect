# AlumBridge — IIIT Delhi Alumni & Mentorship Platform (Frontend)

AlumBridge is a premium alumni networking and intelligent career-mentorship platform for **IIIT Delhi** (built on the **UniConnect** B2B multi-college platform architecture).

## 🚀 Key Features
- **Cinematic 3D Hero Experience**: Pointer-based 3D tilt with real-time perspective depth, interactive top-match showcase card, and 3 layered floating alumni cards.
- **Explainable Career Goal Finder**: Transparent deterministic matching based on career ambitions, target skills, industries, and mentor expertise.
- **Alumni Explorer**: Search by name, company, role, skills, graduation batch, and mentorship availability.
- **Rich Profile Modals**: "Why this mentor?" explainability, career milestones, mentorship topics, and 1-click introduction requests.
- **Network Visualization**: Interactive SVG topology graph showing connected nodes across students, alumni, mentors, companies, and disciplines.
- **Opportunities Board**: High-impact internships, full-time positions, and research roles with verified alumni referrals.
- **Smart Introduction Assistant**: Tone-adaptive message generator (Professional, Friendly, Concise) with instant clipboard copying.
- **Mentorship Request Flow**: Complete lifecycle tracking with local state persistence and toast feedback.

## 🛠️ Technology Stack
- **Framework**: React 18 with Vite
- **Typography**: Manrope, Inter, Space Grotesk
- **Icons**: Lucide React
- **Design Tokens**: Dark Navy (`#050B16`, `#0B1730`), Neon Lime Accent (`#D8FF62`, `#A8EF43`), Crisp White Panels (`#FFFFFF`)

## 💻 Development Setup
```bash
# Install dependencies
npm install

# Start Vite dev server
npm run dev

# Build production bundle
npm run build
```
